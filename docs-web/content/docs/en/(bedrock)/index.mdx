## Features

- **Framework-agnostic** — Works with FastAPI, Flask, Django, CLI tools, and more
- **Manifest-driven modules** — Explicit dependencies and lifecycle management
- **Dependency injection** — Singleton, transient, and scoped service lifetimes
- **Hook system** — Structured call/response extension points with priority ordering
- **Database layer** — SQLAlchemy 2.0 with Alembic migrations
- **Cache system** — Memory and Redis backends with sync/async API
- **Signal system** — Blinker-derived event system
- **CLI tools** — Module management, database migrations, scaffolding

## Quick Start

```bash
# Install
uv add bedrock-core

# Verify
bedrock -v
```
