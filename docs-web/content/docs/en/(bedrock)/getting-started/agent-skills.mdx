Bedrock is designed to work seamlessly with AI coding assistants. To get the best results, install the Bedrock agent skill which teaches your AI assistant about Bedrock's conventions and patterns.

## Why Install the Skill?

Without the skill, AI assistants have to:

1. Scan your entire codebase to understand Bedrock patterns
2. Guess at module structure and conventions
3. Repeat this work in every conversation

With the skill, your AI assistant instantly knows:

- Standard module structure and file organization
- Manifest format and dependency declarations
- Database patterns and model conventions
- Cache system usage
- CLI commands and workflows

## Installation

The Bedrock agent skill is available for multiple AI coding assistants.

### Skills.sh

```bash
npx skills add https://github.com/maacck/bedrock
```

## What the Skill Teaches

The Bedrock agent skill provides:

### Module Structure

Standard file organization for Bedrock modules:

```
modules/
└── my_module/
    ├── __init__.py
    ├── manifest.yaml
    ├── models.py
    ├── entities.py
    ├── service.py
    ├── exc.py
    └── bootstrap.py
```

### Manifest Format

How to write `manifest.yaml` files:

```yaml
title: my_module
description: Module description
version: 0.1.0
depends_on:
  - other_module
commands: "commands:app"
```

### Layer Boundaries

Where different types of code belong:

| Layer | File | Purpose |
|-------|------|---------|
| Data | `models.py` | SQLAlchemy models |
| Validation | `entities.py` | Pydantic models |
| Logic | `service.py` | Business logic |
| Errors | `exc.py` | Module exceptions |
| Lifecycle | `bootstrap.py` | Hooks |

### Anti-Patterns

What NOT to do when working with Bedrock:

- Don't import HTTP types in service layer
- Don't eagerly instantiate settings at module level without `SettingsProxy` if env vars may not be ready
- Don't bypass `ModuleRegistry.install()` for loading modules
- Don't put API endpoints in service files

## Manual Setup

If you prefer to set up conventions manually, install skills to your project and edit by yourself. This folder contains all the conventions that the skill provides.
