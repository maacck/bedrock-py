## Choose a skill

| Skill | When to use it |
| --- | --- |
| `bedrock` | The original application skill, with its guide, references, and templates bundled for offline use. |
| `bedrock-live` | For applications with access to the docs site. The assistant reads relevant Markdown guides and checks them against your installed version. |
| `bedrock-cli` | For project scaffolding and code generation. Can be used alongside either application skill. |

## Installation

Choose one application skill:

```bash
npx skills add maacck/bedrock-py --skill bedrock
# Or, to use the live documentation:
npx skills add maacck/bedrock-py --skill bedrock-live
```

For a manual installation, copy the entire `skills/bedrock/` or `skills/bedrock-live/` directory into your assistant's skills directory.

## Match your project's version

`bedrock-live` reads Markdown guides directly. The [topic index](/llms.txt) reports the documented `bedrock-core` version. If it differs from your application's installed version, consult the [changelog](/docs/changelog) between the two versions. Pinning the skill does not pin the website.

The bundled `bedrock` skill declares its version in `metadata.bedrock-core`. Install it from the matching release tag if your application uses an older version.
