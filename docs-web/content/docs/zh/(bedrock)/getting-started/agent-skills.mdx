## 选择技能

| 技能 | 适用场景 |
| --- | --- |
| `bedrock` | 原版应用开发技能，自带指南、参考资料和模板，可离线使用。 |
| `bedrock-live` | 适用于可联网的应用开发环境。助手按任务读取线上 Markdown 指南，并与应用安装的版本核对。 |
| `bedrock-cli` | 创建项目骨架或生成代码；可搭配任一应用开发技能。 |

## 安装

两种应用开发技能选一个即可：

```bash
npx skills add maacck/bedrock-py --skill bedrock
# 如需使用在线文档，改用：
npx skills add maacck/bedrock-py --skill bedrock-live
```

手动安装时，把整个 `skills/bedrock/` 或 `skills/bedrock-live/` 目录复制到助手的技能目录。

## 核对项目版本

`bedrock-live` 直接读取 Markdown 指南。[主题索引](/llms.txt)标明文档对应的 `bedrock-core` 版本。如果它与你的应用实际安装的版本不同，请在[更新日志](/docs/changelog)中查看两个版本之间的变更。固定 skill 版本不会固定网站版本。

原版 `bedrock` 在 `metadata.bedrock-core` 中标明内置指南的版本。如果应用使用旧版，可从对应的 release tag 安装该技能。
