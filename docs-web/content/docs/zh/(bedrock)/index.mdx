## 特性

- **框架无关** — 可与 FastAPI、Flask、Django、CLI 工具等配合使用
- **基于清单的模块** — 显式依赖关系与生命周期管理
- **依赖注入** — 支持 singleton、transient 和 scoped 服务生命周期
- **Hook 系统** — 带优先级排序的结构化调用/响应扩展点
- **数据库层** — SQLAlchemy 2.0 与 Alembic migrations
- **缓存系统** — 提供内存与 Redis 后端，支持同步/异步 API
- **信号系统** — 基于 Blinker 派生的事件系统
- **CLI 工具** — 模块管理、数据库迁移、脚手架生成

## 快速上手

```bash
# Install
uv add bedrock-core

# Verify
bedrock -v
```
